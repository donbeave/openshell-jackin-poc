# Isolated Docker gateway

## Profile

- Host: macOS 27.0 arm64, Apple T6050; 18 CPUs; 128 GiB RAM.
- OpenShell release: `v0.1.5`, commit `bdb956f2cd65a635f1294fccf1d138d263bf650f`.
- Gateway and CLI: `0.1.5`. Gateway binary SHA-256: `60b562d2d78cab122bd998f14f6b5a22f1a20e4bb77943a25498caee8d041ec9`.
- Docker context: `orbstack`; endpoint `unix:///Users/example/.orbstack/run/docker.sock`; client `29.9.2`, engine `29.8.2`, Linux arm64.
- Gateway name: `ojp-20261024-gw`; endpoint `https://127.0.0.1:18770`; bind address loopback only.
- Gateway process is manually run outside OpenShell. PID at capture: `44804`. The dedicated state and CLI config directories are under this experiment directory.
- mTLS CA, server and client credentials generated by the v0.1.5 `openshell-gateway generate-certs` command. Separate CA B used only for negative test. Private files mode `0600`; ignored by Git and excluded from evidence.
- Docker driver: `0.1.5`; `allow_driver_config=true`; external resource admission stays enabled with default label requirements.

## Reproduce

1. Generate test credentials: `openshell-gateway generate-certs --output-dir /Users/example/openshell-jackin-poc/experiments/gateway/certs --server-san 127.0.0.1`.
2. Run `experiments/gateway/run-gateway.sh` in a terminal. It listens on loopback port 18770. Keep that process running.
3. In another terminal, run `OPENSHELL_LOCAL_TLS_DIR=/Users/example/openshell-jackin-poc/experiments/gateway/certs XDG_CONFIG_HOME=/Users/example/openshell-jackin-poc/experiments/gateway/config XDG_STATE_HOME=/Users/example/openshell-jackin-poc/experiments/gateway/state openshell gateway add https://127.0.0.1:18770 --local --name ojp-20261024-gw`.
4. Run `experiments/gateway/client.sh status -o json`, `.../client.sh sandbox list -o json`, and `.../client.sh gateway info -o json`.

This gateway uses TLS and mTLS client authentication. `--gateway-insecure` was used only for a negative test that isolates missing client authentication; the positive path verifies the server with the gateway CA. Never use the preliminary plaintext configuration for credentials or outside loopback.

## Evidence

See [evidence.md](evidence.md). No Jackin code or OpenShell source was changed. The gateway is not an OpenShell-managed companion. It remains an experiment-owned external gateway process; stop it with `Ctrl-C`. Do not delete the experiment directory before the parent `cleanup.sh` removes experiment-owned containers/resources.

The Docker driver also requires the separate launch signer. `gateway.toml` explicitly points `[openshell.gateway.gateway_jwt]` at the generated `certs/jwt/` bundle. The gateway startup log must report `gateway-minted sandbox JWT enabled`. Listener mTLS alone can pass status/health checks while Docker sandbox creation fails with `docker sandboxes require launch-scoped gateway authentication`.
