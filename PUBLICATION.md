# Public research snapshot

This repository contains the complete source/evidence bundle for the OpenShell runtime proof of concept and subsequent Jackin product-readiness analysis. Start with [AGENT_HANDOFF.md](AGENT_HANDOFF.md) and [JACKIN_REWRITE_READINESS.md](JACKIN_REWRITE_READINESS.md).

## Privacy and provenance

This is a sanitized publication copy. The original local evidence and ZIP were preserved unchanged. No prototype, negative case, research report or independent review was omitted.

Public-copy substitutions remove the original local home path and machine hostname, unique macOS temporary-directory identifiers, an unrelated project's names in the disk audit, the three unrelated original sandbox UUIDs mentioned in the incident, and ephemeral gateway token-reference values. Replacement UUIDs are placeholders; they are not credentials or live targets. Public GitHub source URLs, attribution, source commit pins, test-instance IDs, versions, capability outcomes and experimental measurements remain available.

Historical command strings now show placeholder paths and some incident identifiers. This is not a fresh runtime run. Historical hashes of transformed report/script content may describe the private original. ARCHIVE_MANIFEST.json is regenerated for the actual public files; it excludes itself. Unmodified binary result fixtures and their checksums retain their original bytes.

Generated keys, actual agent credentials, virtualenvs, Docker image binaries, VM disks and live runtime state were already removed before packaging. Public base/source references remain. A secret scanner and a separate publication review were used before publication; those checks are evidence, not a guarantee that a scanner can recognize every possible sensitive string.

Do not blindly run cleanup or collateral-restoration scripts. They document original experiments and require a separate disposable environment, fresh test names/configuration and newly issued test credentials. The restoration script uses placeholder IDs in this public copy.
